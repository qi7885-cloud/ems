1Chart.js 字体粗细传了字符串，类型不匹配P0
src/pages/Dashboard.tsx:99:174:229

三处图表的 tooltip 配置里写了 weight: '600'。Chart.js v4 的 FontSpec.weight 类型为 number | 'bold' | 'normal' | 'lighter' | 'bolder'，字符串 '600' 不属于该联合类型，因此 tsc 报 TS2322。

- titleFont: { size: 13, weight: '600' },
+ titleFont: { size: 13, weight: 600 },
// 注意：同一文件 ticks 里的 weight: 500 是数字，没问题；
// 只有这三处 titleFont 被加了引号。
修复：去掉三个引号，改为数字 600（或直接用 'bold'）。改动 3 个字符即可解开构建。
